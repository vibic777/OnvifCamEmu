# Проверка надёжности — 1.8.1, 30.09.2026

Проверен Python-проект в `src/onvif_emu`, сетевые обработчики, жизненный цикл
процессов, события, конфигурация, состояние, аккаунты и упаковка.
Локальный игнорируемый каталог `OnvifCamEmuGo` в эту ревизию не входит.

## Исправления

1. **FFmpeg при отмене снимка:** дочерний процесс принудительно завершается и
   собирается также при отмене HTTP-запроса. Одновременно создаются максимум
   два снимка на устройство, чтобы параллельные запросы не запускали десятки FFmpeg.
2. **Остановка видеоканала:** сначала завершается задача запуска/перезапуска,
   затем её процессы. Устранена гонка, оставлявшая новый процесс после остановки.
3. **Завершение MediaMTX:** вывод продолжает читаться во время остановки;
   заполненный stdout не должен блокировать ожидание завершения процесса.
4. **Windows HANDLE:** для CloseHandle заданы указатели правильной разрядности.
   Это устраняет усечение 64-битных дескрипторов и риск их утечки.
5. **Частичный запуск:** ошибка настройки HTTP/Discovery и отмена запуска
   проходят через общий finally с освобождением сервисов.
6. **Повреждённые файлы:** некорректная структура state.json и users.json
   обрабатывается существующим механизмом резервной копии и восстановления.
7. **Сохранение состояния:** ошибка диска не убивает периодическую задачу;
   запись повторяется, файловый ввод-вывод вынесен из основного цикла событий.
8. **Очереди событий:** параллельные pull-запросы не могут одновременно извлечь
   один элемент. Удалённые/вытесненные подписки будят ожидающих читателей.
9. **ONVIF PullMessages:** HTTP-обработчик ожидает асинхронно, без блокировки
   общего пула потоков. Ожидание ограничено 30 секундами; отмена освобождает задачу.
   Неизвестный явно переданный токен больше не получает чужую единственную подписку.
10. **Синхронизация событий:** начальные состояния соблюдают фильтр тем подписки.
11. **Push-события:** максимум 128 незавершённых отправок на устройство;
    лишние учитываются в dropped. Задачи отменяются и дожидаются при остановке.
    Push-подписки ограничены 64, просроченные удаляются при добавлении.
12. **Реле:** удаление реле отменяет его отложенный таймер, исключая обращение
    таймера к отсутствующему объекту.
13. **Горячая конфигурация:** применения сериализованы. Настройки, не влияющие
    на видео, не перезапускают кодировщики. Изменение RTSP-путей обновляет MediaMTX.
14. **Каналы:** повторяющиеся ID и пересекающиеся пути основного/дополнительных
    потоков на одном порту отклоняются при валидации.
15. **Диапазоны портов:** границы проверяются до выделения списка; большой диапазон
    не может выделить гигабайты памяти, строится только требуемое число портов.
16. **Веб-сессии:** просроченные сессии очищаются при входе, число сессий ограничено 1024.
17. **Релизы:** версия 1.8.1; pytest исключён из EXE, кэш Python и сгенерированные
    Windows-spec файлы исключены из Linux-архива.

18. **Linux:** поиск vendor-бинарников учитывает платформу; архив из Windows
    сохраняет исполняемые права для FFmpeg, MediaMTX и shell-скриптов.
