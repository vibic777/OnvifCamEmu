# OSD и помехи / OSD and trouble simulator

## OSD: время, дата, картинка

Впечатываются в видео **всех каналов и всех профилей** (как у настоящей камеры: клиент получает их в самом потоке).
GUI: раздел **OSD**, применяется кнопкой «Сохранить» (потоки перезапускаются на 1–2 с). Время — часы компьютера эмулятора.

| Элемент | Настройки |
|---|---|
| Штамп времени / даты | вкл/выкл, формат (strftime), положение (9 точек или свои X/Y в %), размер шрифта (px для 1080p, для профилей пересчитывается), шрифт обычный/моноширинный, цвет и непрозрачность текста, цвет и непрозрачность фона (0 = прозрачный), тёмная обводка |
| Картинка (логотип) | вкл/выкл, файл (**загрузить** в `osd/` рядом с программой **или указать путь** на компьютере эмулятора, «Обзор»), положение, ширина в % кадра, непрозрачность, «прозрачный цвет» (напр. белый фон JPEG → прозрачный), подложка с цветом и непрозрачностью (0 = нет) |
| Служебная индикация | прежний HUD: PTZ-стрелки, события, рамки аналитики, светодиоды реле |

Форматы: `%H:%M:%S`, `%H:%M`, `%I:%M:%S %p`, `%d.%m.%Y`, `%Y-%m-%d`, `%d/%m/%Y`, `%d %b %Y`, `%a %d.%m.%Y`; можно добавить
свой текст (`%H:%M:%S  CAM 1`). Если время и дата в одном углу, они встают друг под другом. Картинки: PNG (с прозрачностью),
JPG, BMP, GIF (первый кадр), WebP, TIFF.

```bash
onvif-emulator --osd-time --osd-time-position bottom-right --osd-time-bg-opacity 0 \
               --osd-date --osd-date-format "%Y-%m-%d" --osd-date-position bottom-right \
               --osd-image D:\logo.jpg --osd-image-key "#FFFFFF" --osd-image-size 12
```

Все поля — также `--set osd.time.size=48` и т. п. (`--list-settings`).

## Ролик без цикла

Каналы → «Зациклить ролик» (по умолчанию включено). Без цикла по окончании: **остановить поток** (камера «пропала»,
`/health` → `pipeline_state` = `ended`, кнопка «Запустить канал заново»), **застыть на последнем кадре** или **чёрный экран**.
CLI: `--channel "1:source=D:\clip.mp4,end=stop|freeze|black"`.

## Помехи (имитация плохой картинки и сети)

GUI: раздел **Помехи**, свой набор на каждый канал, «Применить» перезапускает только этот канал. Пресеты: «Дождь», «Вандал»,
«Плохая сеть», «Дешёвая камера», «Сбросить».

| Группа | Эффект | Как сделано |
|---|---|---|
| Погода/оптика | дождь 0…1 | размытие, смаз (3 кадра), падение контраста/насыщенности, цветная кайма, шум |
| | шум матрицы 0…1 | временной шум |
| | пикселизация 1…32 | огрубление картинки в N раз |
| Вандализм | тряска 0…1 | «дрожание» кадра (crop по синусам), вспышками или постоянно |
| | закрытие объектива | заклеен (чёрный), замазан (размыт), закрашен баллончиком; вспышками или постоянно |
| | событие «Саботаж» | `tns1:VideoSource/Tampering` true/false синхронно с тряской и закрытием (можно выключить) |
| Сеть/поток | потеря пакетов, % | выпадение пакетов видео (серые блоки, смаз до ключевого кадра) |
| | пропуск кадров, % | рывки |
| | замирание | картинка стоит, поток не рвётся; вспышками |
| | битрейт | строго CBR (качество «плавает») или VBR со скачками (всплески детализации); вспышками |
| | узкий канал | потолок битрейта, кбит/с |
| | обрывы связи | поток пропадает на N с каждые X…Y (случайно в диапазоне) секунд/минут/часов; `pipeline_state` = `outage` |

«Вспышки»: эффект включён последние *длительность* секунд каждого *периода* (в конце, чтобы поток не начинался с замирания).

```bash
onvif-emulator --impair "1:rain=0.6" \
               --impair "2:shake=0.7,shake_every=20s,shake_for=4s,cover=spray,cover_every=45s,cover_for=8s" \
               --impair "3:loss=3,stutter=15,freeze=on,freeze_every=25s,freeze_for=3s,bitrate=vbr_jumps,outage=1-4m,outage_len=5-15s" \
               --impair "0:noise=0.2"          # 0 = все каналы
```

Ключи `--impair`: `rain`, `noise`, `pixelate`, `shake`, `cover` (off/black/blur/spray), `tamper_events`, `loss`, `stutter`, `freeze`,
`bitrate` (normal/cbr/vbr_jumps), `cap`; для `shake`/`cover`/`freeze`/`bitrate` — `<имя>_every=15s` и `<имя>_for=3s|always`;
`outage=1-5m` (или `30s`), `outage_len=5-20s`.

## REST

| Метод и путь | Назначение |
|---|---|
| `PUT /api/channels/<id>/impair` | блок помех канала целиком (поля как в `channels[].impair`), канал перезапускается |
| `POST /api/channels/<id>/restart` | запустить канал заново (например, после окончания ролика) |
| `POST /api/osd/image` | загрузить картинку (multipart `file`) → `osd/`, включить |
| `POST /api/osd/image/local` | `{"path": "D:/logo.png"}` — картинка с компьютера эмулятора |
| `GET /api/videos/browse?dir=...&kind=image` | обзор папок (картинки; без `kind` — видео) |

Поля конфигурации — [CONFIG.md](CONFIG.md) (`osd.time`, `osd.date`, `osd.image`, `channels[].source.end_action`, `channels[].impair`).
