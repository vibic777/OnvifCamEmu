# FAQ

**Как задать порт/журнал при запуске exe?** Ключами: `--onvif-port`, `--auto-port`, `--log-level`, `-L`, `--log-dir`. Оба exe (консольный и `-gui`) принимают одинаковые ключи, см. [CLI.md](CLI.md).

**Нужен ли GUI?** По умолчанию да: запустите без `--headless` и откройте `http://IP:8080/`. Для фона: `--service` (GUI остаётся). Без браузера: `--headless` / `--no-gui`.

**Как поставить свой ролик?** Каналы → «Источник видео». Вариант 1 — «Загрузить и включить»: файл копируется в `video/` рядом с программой (или в `video_dir`; папку задают `--video-dir` или «Папка видео» в Системе). Вариант 2 — путь к файлу, который уже лежит на компьютере эмулятора (или «Обзор»), без копирования. Ход загрузки и ошибки видны прямо в карточке канала.

**Какие форматы?** Всё, что читает FFmpeg: MP4, M4V, MOV, MKV, WebM, AVI, WMV, FLV, MPEG/MPG, VOB, TS/M2TS/MTS, 3GP, OGV, MXF и др. H.264 отдаётся как есть, остальное перекодируется в H.264 (клиенту обещан H.264). Файл без видеодорожки отклоняется с сообщением.

**Можно два эмулятора на одном компьютере?** Да, с разными портами ONVIF и RTSP. Служебные порты MediaMTX (API, HLS, WebRTC, RTP/RTCP) второй экземпляр при занятости переносит сам — это видно в `/health` (`mediamtx_ports`) и в журнале.

**Windows-служба?** `.\scripts\install-service.ps1` (администратор). Не используйте `--headless`, если нужна настройка в браузере.

**Почему ODM не видит камеру?** UDP 3702 и multicast `239.255.255.250`. На Windows проверьте брандмауэр. Можно добавить устройство вручную: `http://IP:8080/onvif/device_service`.

**Поток не открывается.** `onvif-emulator doctor` — есть ли FFmpeg и MediaMTX, свободен ли 8554. Для Docker задайте `PUBLIC_HOST`.

**Как сменить пароль?** Свой — меню пользователя справа вверху; любой (администратор) — раздел «Пользователи»; также ONVIF SetUser и `--password`. RTSP использует ту же пару.

**Забыл пароль admin.** Удалите в `data/users.json` строку `"password"` у admin и перезапустите — пароль станет `admin` (или `--reset-admin`).

**Какие есть роли?** Администратор (всё), Оператор (просмотр своих каналов и PTZ), Наблюдатель (только просмотр). Каналы можно ограничить — это действует и в ONVIF, и в RTSP. См. [USERS.md](USERS.md).

**Веб-интерфейс всё время спрашивает пароль.** С 1.8 вход один раз на сеанс, а превью видео идёт через эмулятор — окно логина MediaMTX больше не появляется.

**Сколько каналов?** 1..64. На типичном ПК без транскода комфортно до ~8×1080p remux.

**H.265?** `encoder.codec: h265` (нужен libx265 в сборке FFmpeg).

**Где логи?** В консоли первая строка `Log file: ...`. Обычно `onvif-emulator.log` рядом с программой; если папка не даёт писать (System32 / двойной щелчок по venv) — `%APPDATA%\onvif-emulator\`. Уровень: `--log-level DEBUG` или `-v`. Падения пишутся в этот файл.

**Окно сразу закрывается и пишет про MediaMTX?** Это не требование «сначала вручную запусти MediaMTX». Эмулятор сам поднимает его как дочерний процесс. Если бинарника нет или нет прав на запись `data\mediamtx_<порт>.yml`, RTSP выключен, но веб-GUI должен остаться. Смотрите `Log file:` и не закрывайте консоль. Запуск: `onvif-emulator --service` из PowerShell в папке проекта.

Виртуальное окружение `.venv` в git не кладётся. Локально: `.\scripts\venv.ps1` / `./scripts/venv.sh`. Снос: `.\scripts\clean.ps1 -All`.

**Консольная или GUI-версия — в чём разница?** Это одна программа и один и тот же веб-интерфейс (отдельного оконного интерфейса нет). `*-gui.exe` просто запускается без окна консоли: сам открывает браузер, живёт в трее, при занятом порту берёт свободный. Ключи у обеих одинаковые.

**Где взять адреса каналов и профилей?** Веб-GUI → «Подключение»: адрес ONVIF, RTSP-адрес и ONVIF-токен каждого профиля (`profile_N`, `profile_N_sub`, `profile_N_third`), снимки, шаги для ODM и VLC. Без JavaScript — `http://IP:порт/info`.

**Можно несколько видов аналитики на одну камеру?** Да: Диагностика → «Добавить событие» → тип «Аналитика» → вид (линия, зона, подсчёт, праздношатание…). Правил сколько угодно, у каждого свой таймер (постоянный или случайный диапазон, секунды/минуты/часы). Из консоли — `--rule`, см. [DIAGNOSTICS.md](DIAGNOSTICS.md).

**Ролик крутится по кругу?** Да, по умолчанию. Каналы → снять «Зациклить ролик»: по окончании поток остановится (или застынет на последнем кадре / покажет чёрный экран — на выбор). CLI: `--channel "1:source=clip.mp4,end=stop"`.

**Как поставить время, дату или логотип на видео?** Раздел OSD — у каждого элемента свои формат, положение, размер, цвета и прозрачный фон; картинку можно загрузить или указать путь на компьютере эмулятора. См. [OSD_IMPAIR.md](OSD_IMPAIR.md).

**Как проверить клиент на плохой картинке и сети?** Раздел «Помехи»: дождь, тряска, закрытие объектива, потеря пакетов, рывки, замирания, скачки битрейта, обрывы связи — на каждый канал, есть готовые пресеты. CLI: `--impair`.
